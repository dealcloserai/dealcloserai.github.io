Delete your account

Settings includes Delete account for the sign-in that is already on this device. After you confirm, the app asks DealCloser’s server to delete that sign-in account, saved review text, and document fingerprints. A new anonymous account is not created in order to delete an older one. If this device no longer has the original sign-in, deletion is not started.

This device tells you the account was deleted only when the server reports that the sign-in account was deleted. If the server cannot be reached, or the sign-in account is still open, the account has not been deleted. Removing the app does not by itself delete the server record.

Deleting the account does not cancel the Apple subscription. Cancel that subscription in Apple ID settings.
